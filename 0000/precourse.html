Before the course

Prepare for the training

Please complete the following preparations before the training begins. Some activities are required in advance, while others are recommended to help you get the most out of the training.

Getting started

Please work through the preparation activities below before the course begins. If you have any questions, please contact the course organisers.

Preparation checklist

Accounts

Preparing for the workshop

This course includes hands-on computer exercises. Please make sure that you have access to the required accounts and software before the course starts.

Life Science ID

The Life Science Login enables researchers to use their home organisation credentials or other supported identities to sign in and access the services required for the course.

Instructions

Please create your account before the course.

  1. Open the registration page.
  2. Choose your home organisation.
  3. Complete the registration form.
  4. Review and accept the terms.
  5. Verify your email address.
  • Create a Life Science ID
  • Learn more about Life Science Login

Course platform account

You will use the course platform to access materials, exercises and other course resources.

Instructions

Please create your account before the course begins.

Use the same email address that you used when registering for the course.

  • Open the course platform

Hardware requirements

Computer requirements

Please bring a computer that meets the following minimum requirements.

RAM
8 GB or more
Storage
20 GB available space
Processor
Dual-core processor or better
Internet
Reliable broadband connection

Instructions

Please bring the same computer that you will use during the practical sessions.

If your computer does not meet these requirements, please contact the course organisers before the course.

OBS

If you are unable to bring a suitable computer, please contact the organisers as soon as possible.

Software requirements

Please install the software listed below before attending the course. You may need to contact your local IT department if you do not have administrative rights on your computer.

Git

Git is required for the practical exercises during the course. No previous experience with Git is required.

Instructions

  1. Install Git before the course.
  2. After installation, open a terminal and run: git --version
  3. You should see the installed Git version.
  • Git installation
  • Git setup guidance

R

R is required for the statistical exercises.

Instructions

Install the latest stable version of R.

If you already have R installed, please check that your version is reasonably recent.

  • Download R

RStudio

RStudio provides an integrated development environment for working with R.

Instructions

Install R before installing RStudio.

After installation, open RStudio once to make sure that it starts correctly.

  • Download RStudio
